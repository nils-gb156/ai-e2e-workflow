# Auftrag: Testlauf

Den im Projektprofil angegebenen Befehl für den geplanten Batch ausführen. Die Umgebung und Dienste gemäß Profil vorbereiten. Befehl, Zeitpunkt, Batch, Git-Stand und relevante lokale Änderungen sowie die zu diesem Lauf gehörigen Artefakte festhalten. Bei veralteten oder unvollständigen Artefakten keine Verifikation vortäuschen. Anschließend eine neue Session für den Verifier starten.

```text
Führe den im Projektprofil <Pfad> angegebenen Testlauf für <Batch> aus. Halte Befehl, Ergebnis und zugehörige Artefakte fest. Ändere keine Tests oder Produktdateien. Nenne den nächsten Schritt.
```
